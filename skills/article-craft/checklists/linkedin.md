# LinkedIn Checklist

Policy references: [../references/platforms/linkedin/](../references/platforms/linkedin/).
Reminders where each rule comes from are inline; when in doubt, re-read the
reference before claiming a rule.

## Adaptation model (this is not an article platform check)
- [ ] The **article remains primary**; the post is an attributed pointer
- [ ] Post text ≤ 3,000 characters (official documented limit)
- [ ] Every factual claim in the post traces to the source article
- [ ] No new facts, numbers, or quotes invented during adaptation
- [ ] First line hooks without clickbait (line truncation: "see more")

## AI content (POLICY)
- [ ] No "AI slop": generic, unsolicited, automated-feeling content
      (LinkedIn's official definition)
- [ ] Content created with AI assistance disclosed where LinkedIn's policy
      requires it
- [ ] Real author voice and experience present

## Professional Community Policies
- [ ] No spam, no engagement bait, no misleading claims
- [ ] No third-party content posted as if the author's own
- [ ] Hashtags: a handful, actually relevant (no hashtag walls)

## Articles (long-form, RECOMMENDATION)
- [ ] If publishing an article: title, structure, and sources checked like any
      other platform — plus LinkedIn's policy rules above

## Final
- [ ] Post reads as written by a human, for humans, about real work
- [ ] Run `article-craft check post-or-article.md --platform linkedin` (CLI)
