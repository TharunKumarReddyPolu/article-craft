# Fact-Check Checklist

## Coverage
- [ ] Every statistic verified against a Tier 1-2 source
- [ ] Version-specific behavior checked against the changelog/docs
- [ ] API signatures / command flags tested or verified
- [ ] Dates, names, and titles verified
- [ ] Quotes verified verbatim against the primary source
- [ ] Benchmark numbers: measured by the author (setup described) or cited
- [ ] "Studies show"-class claims either cited or removed

## Classification
- [ ] Each claim classified: VERIFIED / LIKELY / UNVERIFIED / CONTRADICTED /
      OPINION / ASSUMPTION
- [ ] UNVERIFIED and CONTRADICTED claims surfaced to the author
- [ ] Hidden assumptions made explicit in the article text

## Sources
- [ ] Primary sources preferred over commentary
- [ ] Source dates recorded; nothing stale where versions matter
- [ ] Conflicting official sources resolved (newer official wins; conflict noted)
- [ ] URLs recorded for every claim marked VERIFIED

## Honesty
- [ ] No invented citations, statistics, URLs, quotes, or benchmarks
- [ ] If external verification was unavailable: stated explicitly, and all
      affected claims marked UNVERIFIED
- [ ] Author's own measurements marked LIKELY at most, pending their confirmation
