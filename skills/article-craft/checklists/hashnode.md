# Hashnode Checklist

Policy references: [../references/platforms/hashnode/](../references/platforms/hashnode/).
Reminders where each rule comes from are inline; when in doubt, re-read the
reference before claiming a rule.

## Publishing mechanics
- [ ] Title present and honest
- [ ] Cover image selected or deliberately omitted
- [ ] Canonical URL set if cross-posting (author-only setting)
- [ ] Tags (up to 5) actually match the content

## Markdown & embeds
- [ ] Markdown is valid; code blocks have language hints
- [ ] Markdown shortcuts (e.g., `/` embeds) understood; no broken embed HTML
- [ ] Widget/Embed code only where Hashnode supports it

## Content quality
- [ ] Reader gets real value; not a thin rehash or promo piece
- [ ] Author contribution present (experience, opinion, results)
- [ ] Technical claims verified against tier-1 sources

## Community & conduct
- [ ] No plagiarism; copied material attributed and transformed
- [ ] No spam, engagement farming, or undisclosed affiliate content
- [ ] AI usage handled per Hashnode's AI content position (disclosure where
      the platform requires it)

## Final
- [ ] All claims either verified or honestly hedged
- [ ] Run `article-craft check article.md --platform hashnode` (CLI)
