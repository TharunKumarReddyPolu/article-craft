# Substack Checklist

Policy references: [../references/platforms/substack/](../references/platforms/substack/).
Reminders where each rule comes from are inline; when in doubt, re-read the
reference before claiming a rule.

## Title & subject
- [ ] Post title IS the email subject line — evaluated as both
- [ ] Subject line strong enough for email (specific, not clickbait)
- [ ] Subtitle used deliberately (preheader in email)
- [ ] Optional distinct email subject line set if it differs from the title

## Content (Content Guidelines — POLICY)
- [ ] Editorial content, not email marketing (Substack's own line)
- [ ] Original writing; substantial value to the reader
- [ ] No plagiarism; quotes attributed
- [ ] No spam, deceptive practices, or impersonation

## AI content (2026)
- [ ] Substack now runs reader-facing AI-text detection — disclosure or clear
      authorial contribution strongly recommended
- [ ] Reader reports ("Seems like AI") are part of enforcement: any
      AI-generated-sounding filler removed
- [ ] Author voice and first-hand experience present throughout

## Formatting
- [ ] Sections/subheadings used for newsletter readability
- [ ] Images have alt text where the editor supports it
- [ ] Code blocks formatted (treated as markdown)

## Final
- [ ] All claims either verified or honestly hedged
- [ ] Run `article-craft check article.md --platform substack` (CLI)
