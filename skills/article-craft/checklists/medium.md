# Medium Checklist

Policy references: [../references/platforms/medium/](../references/platforms/medium/).
Reminders where each rule comes from are inline; when in doubt, re-read the
reference before claiming a rule.

## Title & subtitle
- [ ] Title accurately represents the article (disqualifier otherwise)
- [ ] Not sensationalistic AND not overly generic/mysterious/formulaic
- [ ] Subtitle adds the promise, angle, or scope

## Content quality
- [ ] Reader gets real value (not a sales pitch or attention bid)
- [ ] Non-derivative: not a rehash/summary of other sources
- [ ] Author contribution present (experience/insight/position)
- [ ] No clickbait anywhere in title/subtitle/cover

## Policy
- [ ] AI usage disclosed per Medium's AI policy (if AI-generated text or
      images involved) — see ai-policy.md
- [ ] AI-generated text NOT behind the Partner Program paywall
- [ ] AI-generated images captioned as AI-generated
- [ ] Affiliate links disclosed (FTC requirement via Medium Rules)
- [ ] No third-party advertising/sponsorship
- [ ] Copyright: images/code/text rights cleared or licensed

## Formatting
- [ ] Formatting is readable (headings, paragraphs, code blocks tagged)
- [ ] Links descriptive (no bare "click here")
- [ ] Embeds pasted as URLs (no embed code — Medium doesn't support it)

## Metadata
- [ ] Up to 5 topics, all actually matching the content
- [ ] No excessive @mentions
- [ ] Canonical link considered if cross-posting (set in story settings;
      only the author can set it)
- [ ] If the story is about Medium/Partner Program: tagged `medium-meta`
      (Network distribution only)

## Final
- [ ] Distribution guidance reviewed against distribution.md
- [ ] Author has read the final draft top to bottom
- [ ] This checklist does not guarantee Boost or distribution — say so
